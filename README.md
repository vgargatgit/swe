# SWE Field Guide

A static GitHub Pages site for the practical backend and system-design course.

## What is included

- Day-by-day lessons for the topics covered so far, currently Day 1 through Day 36.
- A full roadmap of the remaining backend/system-design topics.
- Mermaid diagrams for visual models, sequences and state machines.
- A compact SPA-style site that works without a build step.

## Local preview

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

The Mermaid renderer is loaded from jsDelivr at runtime.
